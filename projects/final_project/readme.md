# Автоматический конвейер (Pipeline) оценки стоимости недвижимости на рынке США

Данный проект представляет собой коммерчески применимый ИТ-продукт — сквозную автоматическую систему предобработки данных и прогнозирования стоимости жилья на массовом рынке США с использованием алгоритмов машинного обучения.

В репозитории реализована монолитная архитектура, которая принимает на вход сырые анкетные данные пользователей с веб-сайта, самостоятельно проводит очистку шкал, обогащает их признаками без утечки информации (*Data Leakage*) и за микросекунды возвращает долларовый прогноз.

---

## Исследовательские Jupyter Ноутбуки (Проведение экспериментов)

Весь научно-практический цикл исследования разбит на два изолированных этапа и подробно задокументирован в интерактивных ноутбуках проекта:

1. [**Ноутбук №1: Data Cleaning and Imputation**](https://github.com/emozdir/Projects/blob/master/projects/final_project/Data_Cleaning_and_Imputation.ipynb)
   * **Назначение**: Первичный комплексный аудит «сырых» данных, декомпозиция сложных вложенных JSON-структур, парсинг регулярными выражениями и ликвидация риелторского шума.
   * **Ключевые результаты**: Раскрыты планировочные сдвиги в признаках, проведено кросс-функциональное восстановление климатических систем HVAC на 30 000 объектах, реализована жесткая фильтрация информационного вакуума и осуществлено внешнее геокодирование через кэшированные API-запросы. Сформирована математически чистая матрица признаков.

2. [**Ноутбук №2: EDA and Modeling**](https://github.com/emozdir/Projects/blob/master/projects/final_project/EDA_and_Modeling.ipynb)
   * **Назначение**: Углубленный разведочный анализ данных (EDA), проверка статистических эконометрических гипотез, математическое сжатие шкал, Feature Engineering и фаза ML-моделирования.
   * **Ключевые результаты**: На основе статистических критериев (Д'Агостино, Манна-Уитни, Краскела-Уоллиса) доказана значимость и характер распределения всех фичей. Разработан комплекс кастомных трансформеров, проведена байесовская оптимизация гиперпараметров ансамблей (`XGBoost`, `LightGBM`, `CatBoost`) во фреймворке `Optuna` и осуществлена финальная инференс-сериализация модели.

## Структура репозитория

* `data/` — подпапка, содержащая бинарный файл обученной продакшен-модели (`final_xgb_model.joblib`) и справочник физических географических координат по ZIP-кодам.
* `notebooks/` — исследовательские ноутбуки с разведочным анализом данных (EDA) и фазой оптимизации ансамблей.
* `server.py` — серверный скрипт на базе веб-фреймворка Flask, обеспечивающий работу продакшен-инференса и API-эндпоинта `/predict`.
* `client.py` — автономный скрипт для симуляции POST-запросов со стороны пользователя веб-сайта.
* `requirements.txt` — конфигурационный файл со всеми зафиксированными версиями системных библиотек Python.

## Ключевые инженерные результаты проекта

1. **Глубокая очистка и рокировка данных (Data Cleaning)**: Из сырого риелторского массива успешно устранены масштабные структурные сдвиги (когда жилая площадь и ванны были ошибочно записаны в спальни). Скрытая аренда отфильтрована по текстовому маркеру `/mo`, а незастроенная пустая земля (`land`) и квартиры (`apartment`) изолированы от ложного внесения искусственного шума в непрерывные геометрические величины площадей.
2. **Десериализация JSON и Cross-Feature импутация**: Проведена полная распаковка сложных вложенных JSON-массивов образовательной (`schools`) и строительной (`homeFacts`) инфраструктуры. Реализован алгоритм перекрестного кросс-функционального восстановления климатических систем (`Heating` и `Cooling`) по изолированным регулярным маскам, что позволило закрыть до 30 000 взаимных пропусков без привлечения внешних API.
3. **Кастомный препроцессинг**: Спроектирован и внедрен контур из 4 кастомных трансформеров Scikit-Learn (`EffectiveAgeTransformer`, `GeographicCoordinatesTransformer`, `BedsBathsCleaner`, `OutlierClipper`). Они обеспечивают послойную импутацию координат, ординарное целочисленное квантование комнат и инференс-клиппинг площадей на основе статистик, рассчитанных строго внутри тренировочных фолдов, что гарантирует 100% защиту от утечки данных (*Data Leakage*).
4. **Финальный ансамбль**: На основе кросс-валидации и байесовского поиска параметров фреймворком `Optuna` абсолютным чемпионом признан алгоритм **XGBoost Regressor**.
5. **Борьба с переобучением**: За счет жесткой L1/L2-регуляризации структуры деревьев зазор метрик между Train и Validation выборками сократился до безопасных **4.1%**, обеспечив модели точность **$R^2$ = 0.8195** при средней абсолютной ошибке **MAE = \$98.5k**.
6. **Автоматизация таргета**: Благодаря контейнеру `TransformedTargetRegressor` модель самостоятельно логарифмирует цену при обучении и автоматически экспоненциирует её при прогнозе, возвращая ответ сразу в реальной шкале цен в долларах.

## Инструкция по локальному развертыванию веб-сервиса

### Шаг 1. Клонирование репозитория и установка зависимостей
```bash
git clone https://github.com
cd имя-репозитория
pip install -r requirements.txt
```

### Шаг 2. Запуск Flask-сервера
Включите локальный веб-сервер. Скрипт автоматически найдет веса модели в подпапке `data/`, восстановит код кастомных классов и откроет порт для приема данных:
```bash
python server.py
```
*Успешный статус запуска в консоли:* `* Running on http://127.0.0.1:5000`

### Шаг 3. Запуск симуляции запроса (Тестирование API)
Не закрывая терминал сервера, откройте второе окно консоли и запустите автономный скрипт клиента для отправки тестовых характеристик дома в Неваде:
```bash
python client.py
```
*Ожидаемый ответ от работающего API:*
```json
Статус-код ответа сервера: 200
Успешный ответ от продакшен-API:
 - Расчитанная стоимость объекта: \$617,702.62
 - Статус транзакции: success
```
