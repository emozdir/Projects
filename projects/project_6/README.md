# Сегментация клиентов интернет-магазина подарков

## Описание проекта
Анализ транзакционных данных интернет-магазина подарков, очистка данных, разведывательный анализ и сегментация клиентов на основе RFM-характеристик с применением методов кластеризации.

## Цель
Выделить сегменты клиентов для разработки маркетинговых стратегий и персонализации предложений.

## Этапы работы
1. Предобработка и очистка данных (пропуски, дубликаты, возвраты, специализированные транзакции)
2. Разведывательный анализ (страны, сезонность, товары, клиенты)
3. Построение RFM-таблицы
4. Кластеризация клиентов (KMeans, Agglomerative, DBSCAN)
5. Интерпретация сегментов и маркетинговые рекомендации

## Результаты
Выделены 3 сегмента клиентов:
- **VIP** (19%) — самые ценные клиенты
- **Лояльные** (56%) — стабильная база
- **Спящие** (25%) — требуют реактивации
